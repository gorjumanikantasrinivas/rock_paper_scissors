# Rock · Paper · Scissors 🪨📄✂️

A sleek, dark-themed Rock Paper Scissors game built with vanilla HTML, CSS & JavaScript. Play against the computer with live score tracking, match history, and smooth animations — no libraries needed.

---

## Features

- 🎮 Play against the computer instantly
- 📊 Live scoreboard — tracks Your wins, Ties, and CPU wins
- 🕹️ Animated move reveal with shake effect
- 🏷️ Match history chips showing last 15 results
- 🔄 Reset button to start a fresh session
- 📱 Responsive — works on mobile and desktop

---

## Tech Stack

| Layer      | Technology        |
|------------|-------------------|
| Structure  | HTML5             |
| Styling    | CSS3              |
| Logic      | Vanilla JavaScript|

---

## Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/gorjumanikantasrinivas/rock-paper-scissors.git
   ```

2. Open the project folder
   ```bash
   cd rock-paper-scissors
   ```

3. Open `index.html` in your browser — that's it, no installs needed!

---

## Project Structure

```
rock-paper-scissors/
├── index.html   → Game layout and structure
├── style.css    → Dark theme, animations, responsive design
└── script.js    → Game logic, scoring, match history
```

---

## How to Play

1. Click **Rock**, **Paper**, or **Scissors**
2. The computer randomly picks its move
3. Result is shown instantly in the arena
4. Score updates automatically
5. Hit **Reset Scores** to start over
